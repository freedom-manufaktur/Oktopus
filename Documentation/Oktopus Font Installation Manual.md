# Font Installation
When converting documents from Microsoft Word to PDF, you probably want to provide additional font, which are not part of the system (like `Arial`).
An example is the font [`Inter`](https://rsms.me/inter/) ([GitHub](https://github.com/rsms/inter)), which you may want to download and add to Oktopus.

## Font Installation on Windows
1. Download the required `.ttf` files. Please note that variations, like *Bold*, *Italic*, *Bold Italic* or *Black* must be provided as individual `.ttf` files.
2. Navigate to `%ProgramData%\freedom manufaktur\whoosh Oktopus` and open the folder of your Oktopus instance.
3. Open or create a folder named `Fonts`.
4. Place your `.ttf` files there.
   ![Windows Explorer with fonts folder](<Images/Font Installation/Font Folder Windows.png>)
6. Restart the Oktopus Service.
